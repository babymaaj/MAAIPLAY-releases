# MAAIPLAY releases

Play FL Studio with a game controller (Xbox, PS5 DualSense, PS4 DualShock 4).

**New tester?** Download `MAAIPLAY_v<version>_playtest.zip` from the [latest release](https://github.com/babymaaj/MAAIPLAY-releases/releases/latest), extract it, and read `READ ME FIRST.txt`.

**Already have MAAIPLAY?** You don't need to do anything. The app checks this page and updates itself (Hub > System > Updates). Your settings and binds stay as they are.

Each release has:
- `MAAIPLAY_v…_playtest.zip`: the full app, for first installs
- `maaiplay-update.zip` + `manifest.json`: what the app downloads to update itself
